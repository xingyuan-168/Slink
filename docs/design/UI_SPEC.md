# 画布 UI 说明

状态：用户于 2026-09-11 明确回复“UI通过”，已记录批准。原型是浏览器交互模型，不是真实 DLL，也不构成 DWM 技术验证。

## 正式画布

- Windows 标准顶层窗口，标题 `CQ_SLink 屏幕墙`，支持移动、缩放、最小化、最大化、还原和关闭。
- LOGO 使用用户提供的原始 PNG，等比缩放为大小窗口图标，嵌入 DLL。图标外不使用 LOGO，不叠加到源画面。
- 客户区只包含网格，不包含原型侧边的评审控制面板、网页顶部说明、提示面板及示例内容中的帧号。这些帧号属于模拟的源窗口画面。
- 背景 #101318，标题栏 #20252D，Tile 边框 #353D49，正文 #E7EBF1，辅助文字 #A8B2C0；系统上下文菜单使用操作系统主题。
- 外边距 4 DIP、格间距 4 DIP、Tile 标题区 26 DIP、边框 1 DIP。原生字体 Segoe UI / Microsoft YaHei UI，12 DIP。DPI 按窗口所属显示器换算。
- 网格按指定行列等分，余数像素分配到边界；极小窗口的内容区可以为零，禁止负矩形。
- 标题左侧为源标题，超长单行省略，空标题回退 HWND；右侧只在停放时显示“后台隐藏”文字，不以颜色单独编码状态。
- 每格显示指定客户区 ROI。FIT 等比居中留深色边；STRETCH 填满内容区。不修改源窗口尺寸。

## 状态及交互

| 状态 | 内容区 | 右键菜单 |
|---|---|---|
| 正常 | 实时源画面 | 显示禁用，隐藏可用 |
| DLL 后台停放 | 持续源画面，标题带“后台隐藏” | 显示可用，隐藏禁用 |
| 空槽位 | 易语言底图或深色背景 | 两项禁用 |
| 无效句柄 | 底图，标题标注“窗口失效” | 两项禁用 |
| 映射失败 | 底图，标题标注“映射失败” | 按窗口有效性及可控制性确定 |
| 源被系统隐藏/最小化 | 底图及状态文字 | 隐藏禁用；显示不擅自恢复非本 DLL 停放的窗口 |

- 标题和内容区右键均命中同一个 Tile，菜单顺序为“显示窗口”“隐藏窗口”。不转发鼠标或键盘到源窗口。
- 菜单命令与导出 API 共用内部实现。失败不伪造成功状态；恢复与激活结果分别记录。
- 用户关闭画布时先恢复其拥有的停放窗口，再退出；恢复失败保留画布及会话，给出错误提示并允许重试。
- DLL 多 Session/重复 HWND 共用停放状态，任意关联 Tile 执行显示都会同步。

## 原型评审方法

打开同目录 `PROTOTYPE.html`。侧栏调整行列、FIT/STRETCH、统一 ROI 和模拟底图；场景按钮切换失效/空槽位/完整12路。右键或选中 Tile 后按 Shift+F10 打开菜单。隐藏后帧号继续变化，显示后状态恢复。窗口按钮演示最大化、最小化、关闭与重开；右下角可拖动调整大小。

原型侧栏是评审工具，正式 DLL 参数仍由易语言 API 传入。原型动画不作为真实兼容性证据。实际原生上下文菜单外观随 Windows 主题变化。
