## 审批范围

2026-10-10 用户明确批准本次新增交互：初始化进度/失败重试、右键隐藏/显示、虚拟屏标记、关闭恢复与失败重试；并选择先接入正式 DLL，再由用户统一验收大漠。原型不会安装驱动或操作实际窗口。既有 gwm-wall-v1 外观审批保留为历史。

### 虚拟显示器交互

- 有效槽位标题或画面右键弹出原生风格菜单，显示槽位编号与 HWND；提供“隐藏窗口”“显示窗口”，当前不可用动作禁用。空位和失效窗口不能操作；Shift+F10 为原型键盘入口。
- 正常状态无常驻工具栏；隐藏后标题增加“虚拟屏”文字标记，继续显示捕获画面。相同 HWND 所有槽位共享状态。点击显示恢复原位置；双击先恢复再激活。
- 初始化提示位于画布上部居中卡片，依次显示检查、安装、初始化扩展屏；采用不表示百分比的滚动进度条，尊重 reduced-motion。安装不阻塞画布消息和普通映射。
- 失败卡片用文字说明取消授权、安装失败、需要重启或驱动被占用，并提供“重新检查”；不自动重启系统。仅禁止新的隐藏，已有停放窗口仍可请求显示。
- 关闭画布先显示“正在恢复源窗口”，停止新操作；全部恢复后关闭。恢复失败显示剩余窗口数和“重试恢复”，保留画布、记录与虚拟屏；不把失败报告为关闭成功。
- 宿主异常退出由独立辅助程序执行恢复；无主画布时如恢复失败，辅助程序提供相同文字与重试操作的简洁恢复提示窗口。原型通过“模拟宿主退出”演示结果，不代表本机真实测试。
- 虚拟屏丢失时先恢复窗口，再保留普通映射并显示重新检查入口。
- 右侧场景控制、故障复选框、下方实体/虚拟屏示意和反馈区仅供审阅，不属于正式画布或易语言运行时配置。

审阅步骤：右键隐藏第1格 → 观察标题标记及源窗口移入虚拟屏示意 → 右键显示或双击恢复 → 隐藏多个格子后关闭 → 勾选模拟恢复失败再关闭/重试 → 切换首次安装和取消授权场景。

2026-09-14 接口修订：所有配置在开始映射时确定，运行中不更新；关闭画布自动释放。保留已批准画布外观，原型外层可编辑参数仅作为审阅演示，不代表运行时 DLL 命令。

本次重建的原生画布外观和交互。历史UI审批不继承。PROTOTYPE.html外层参数面板属于审阅工具，不属于正式画布；所有源画面、HWND及激活反馈均为模拟。

## 画布

- Windows标准外框/标题栏，名称“GameWindowMapper · 屏幕墙”，左侧使用input原始LOGO；标准最小化、最大化、关闭。
- 客户区深色背景#111318，边线#353b46，无侧栏和工具条。原型外层面板可切换“只看画布”。
- 行列由调用方指定，按数组横向排列，不随浏览器断点自动换列。每格上方30 DIP标题区，显示编号+标题；长标题省略但保留编号。
- 默认字体Segoe UI/Microsoft YaHei UI，标题12 DIP，文本#e6eaf0；辅助文本#adb5c3。选中/焦点用蓝色边框，状态同时使用文字，不能只靠颜色。
- 映射画面默认拉伸铺满每格的画面区域：以整个请求 ROI 的宽高分别计算水平、垂直缩放，完整保留指定区域内容，允许比例变形；不再因比例不一致留边。超出源客户区的 ROI 部分按对应位置补深色。标题区不占用源 ROI；底图仍等比居中，LOGO 保持原比例。
- 画布resize重新布局，显示和双击命中共用矩形数据。

## 状态与操作

| 状态 | 内容 | 操作 |
|---|---|---|
| 正常 | 实时区域画面 | 双击激活；原型Enter也可模拟 |
| 等待首帧 | 默认/自定义底图+等待文字 | 保留槽位 |
| 最小化 | 底图+已最小化 | 双击恢复并激活 |
| 失效 | 底图+窗口已关闭 | 不激活；改变句柄需关闭后重新启动 |
| 捕获失败 | 底图+捕获失败 | 保留槽位并反馈错误 |
| 无新帧 | 保留末帧 | 不自动断定冻结或黑屏 |
| 强制底图 | 自定义或默认底图 | 仍按原槽位激活有效HWND |
| 空槽位/网格剩余位置 | 深色+编号及空位文字 | 不激活 |

双击标题或内容均作用于该槽位，禁止标题搜索或遍历猜测。单击原型选择槽位仅供配置演示，正式画布不需要参数编辑功能。

## 原型审阅

初始12个数组槽位、3×4布局；示例包含乱序HWND和异常状态。外层控件可调整行列、画布尺寸、15/30/60帧率选项（只展示设置，不模拟性能）、槽位HWND/标题/ROI/状态、PNG/BMP底图、追加与清空。

原型最大化切换扩展预览区域；最小化显示恢复条；关闭只关闭模拟画布并可重新打开，不操作系统窗口。图片上传在浏览器本地读取，不上传服务器。

焦点可见、表单有label、按钮有名称、错误和激活结果使用aria-live。窄屏外层面板移到画布下方；网格列数保持固定。原型不依赖网络、字体CDN或JS框架。
