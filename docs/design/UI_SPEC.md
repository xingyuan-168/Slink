## 画布

- Windows标准外框/标题栏，名称“GameWindowMapper · 屏幕墙”，左侧使用input原始LOGO；标准最小化、最大化、关闭。
- 客户区深色背景#111318，边线#353b46，无侧栏和工具条。原型外层面板可切换“只看画布”。
- 行列由调用方指定，按数组横向排列，不随浏览器断点自动换列。每格上方30 DIP标题区，显示编号+标题；长标题省略但保留编号。
- 默认字体Segoe UI/Microsoft YaHei UI，标题12 DIP，文本#e6eaf0；辅助文本#adb5c3。选中/焦点用蓝色边框，状态同时使用文字，不能只靠颜色。
- 映射内容按整个请求 ROI 横纵分别拉伸铺满，超出源客户区的区域按对应位置补深色；底图与 LOGO 等比显示。标题区不占用源 ROI。
- 画布resize重新布局，显示和双击命中共用矩形数据。

## 状态与操作

| 状态 | 内容 | 操作 |
|---|---|---|
| 正常 | 实时区域画面 | 双击激活；原型Enter也可模拟 |
| 等待首帧 | 默认/自定义底图+等待文字 | 保留槽位 |
| 最小化 | 底图+已最小化 | 双击恢复并激活 |
| 失效 | 底图+窗口已关闭 | 不激活；关闭后重新传入有效句柄 |
| 捕获失败 | 底图+捕获失败 | 保留槽位并显示错误状态 |
| 无新帧 | 保留末帧 | 不自动断定冻结或黑屏 |
| 强制底图 | 自定义或默认底图 | 仍按原槽位激活有效HWND |
| 空槽位/网格剩余位置 | 深色+编号及空位文字 | 不激活 |

双击标题或内容均作用于该槽位，禁止标题搜索或遍历猜测。单击原型选择槽位仅供配置演示，正式画布不需要参数编辑功能。

## 原型审阅

初始12个数组槽位、3×4布局；示例包含乱序HWND和异常状态。外层控件可调整行列、画布尺寸、15/30/60帧率选项（只展示设置，不模拟性能）、槽位HWND/标题/ROI/状态、PNG/BMP底图、追加与清空。

原型最大化切换扩展预览区域；最小化显示恢复条；关闭只关闭模拟画布并可重新打开，不操作系统窗口。图片上传在浏览器本地读取，不上传服务器。

焦点可见、表单有label、按钮有名称、错误和激活结果使用aria-live。窄屏外层面板移到画布下方；网格列数保持固定。原型不依赖网络、字体CDN或JS框架。
