## 环境与方法

- Windows 构建号：CMake 检测为 10.0.26200；MSVC 19.44.35228，SDK 10.0.26100.0，CMake 3.31.10，Win32 Release /MT。
- 测试源客户区 1920×1080，普通外框 1936×1119，DPI 96。虚拟桌面范围与停放坐标见证据文件。
- GDI 源按定时器绘制；D3D 源使用 D3D11 + DXGI + Direct2D，离屏后继续绘制并调用 Present。
- 测试源在客户区顶部绘制固定签名及16位帧号；PoC 映射客户区 0,0,800,600。
- 原子复制可见 PoC 画布的一行像素，再解析签名和帧号，避免逐点取色跨帧造成计数撕裂。该桌面取样仅用于测试，未用作生产映射后端。
- 记录源窗口定时器、绘制计数、Present 返回值和 WGC 收帧数量；不将收到重复帧解释为内容更新。
- 所有停放均使用规格要求的 SetWindowPos 标志，包括 SWP_NOSIZE；不隐藏、最小化、透明化或修改源样式。

## 捕获结果

| 映射后端 / 测试源 | 正常位置画面更新 | 完全离屏 | 恢复位置后 | 结果 |
|---|---|---|---|---|
| DWM / GDI | 通过 | 停帧 | 已执行位置恢复 | 不兼容 |
| WGC / GDI | 通过 | 停帧 | 已执行位置恢复 | 不兼容 |
| DWM / D3D11，右/左/上/下四方向 | 全部通过 | 全部停帧 | 全部恢复更新 | 4项失败，退出码9 |
| WGC / D3D11，右/左/上/下四方向 | 全部通过 | 全部停帧 | 全部恢复更新 | 4项失败，退出码9 |

最终四方向 D3D11 测试采用原子取样。更早 GDI 快速验证采用逐点取样，因而只作为辅助证据；正式门禁结论以 `docs/evidence/` 中的最终四方向日志为准。

典型 DWM 右侧停放：源绘制计数由60增长到106，Present仍返回0，画布帧号保持60，23次取样的变化数为0；恢复后23次变化，源尺寸/位置恢复通过。对应证据：`evidence/dwm-d3d-right.txt`。

WGC 右侧停放：源绘制计数63增长到109，捕获帧总数69增长到93，但画布帧号保持63，变化数为0。说明仅监测 FrameArrived 不能证明画面持续更新。恢复后画布更新恢复。对应证据：`evidence/wgc-d3d-right.txt`。

所有四方向失败的 `rollback=1`，表示已恢复原位置且窗口不变量校验通过。测试源随后关闭，不遗留用户窗口到桌面外。
