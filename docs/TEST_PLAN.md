# 验收清单

当前未执行正式 DLL 测试。以最终测试报告记录每项实际结果和环境。

## 算法和 ABI

- 裁剪负起点、越界、空交集、全客户区、整数溢出。
- FIT/STRETCH、余数像素、DPI、极小网格、容量不足与 FILL 拒绝。
- 真实无修饰导出名、stdcall、64位 Session 返回值、uint64_t 数组及深拷贝。
- 参数错误、无效会话、TLS 错误信息与 UTF-8 缓冲区边界。

## 可控窗口集成

- 自带 GDI 和 D3D 动态测试源；12路3×4，ROI 0,0,800,600。
- 取样可见画布中的动态帧号验证更新；不以 HRESULT 或静态内容判定持续新帧。
- 连续运行30分钟，记录 CPU、GPU、内存、GDI/USER/进程句柄。
- 普通/最大化源各100次隐藏显示，比较坐标、外框/客户区尺寸、Style/ExStyle/DPI/showCmd。
- 多屏、负坐标、100%/125%/150% DPI 和混合 DPI；环境缺失则标记未执行。
- 源关闭、句柄替换、空/重复句柄、损坏图片、恢复失败和激活被拒绝。
- Create/Destroy 100次；多线程更新/销毁/用户关闭，检查资源和死锁。

## 设计原型

- 行列变更与容量错误、FIT/STRETCH、ROI、底图及无效/空槽位。
- 右键/键盘菜单，隐藏时模拟画面继续，显示恢复，关闭恢复模拟源。
- 最大化/还原/最小化/重开、拖动窗口与缩放。
- 无网络依赖、LOGO仅标题图标、键盘焦点、窄屏和常见桌面尺寸。
