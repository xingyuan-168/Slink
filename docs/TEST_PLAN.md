## REQ-GWM-002 原验证计划（已撤回，仅历史）

以下内容适用于此前隐藏版本。专用工具和参数现已从构建移除，不应使用以下历史命令验证当前交付。

只做针对性短验证：GPU 横纵拉伸/偏移/越界、已安装项目设备的非主扩展屏、WGC 动态更新、位置尺寸恢复、重复 HWND、多宿主退出与路径丢失恢复、原生菜单／重试、唯一导出和关闭重开。首次安装本机已由用户允许发布者确认；取消授权、需要重启、其他系统等未实际执行的场景须明确记为未测。易语言和大漠效果由用户在正式 DLL 验收，不以测试源替代。

开发构建先运行 scripts/build.ps1，构建会核验/获取固定驱动包、构建原生 x64 helper 后再嵌入 x86 DLL。-Test 预检项目驱动已安装、输入桌面为本地 Default；测试不会触发首次安装。正式 DLL 的启动本身异步启用虚拟屏，因此单入口生命周期也会临时使用本项目路径。额外 virtual_capture、recovery_integration、canvas_virtual 需显式 GWM_ENABLE_DISPLAY_TESTS=ON，串行执行，只操作专用测试 HWND；存在其他映射／活动路径时跳过，不能算通过。GPU 像素检查捕获自有 HWND，不用桌面覆盖像素。

可复现短检查：scripts/build.ps1 -Test -VirtualDisplayTests。x64 检查恢复提示和请求去重（后者仅使用隔离管道与假显示操作）；x86 检查 single_entry_lifecycle、gpu_geometry、virtual_capture、recovery_integration、canvas_virtual。默认 -Test 仅运行单入口生命周期。测试前等待此前自有辅助进程的短暂退出宽限；不干扰其他活动会话。

canvas_virtual 通过内部原生 WM_COMMAND 菜单 ID 操作本进程画布，没有增加测试导出。检查三窗口和重复槽位、隐藏时正式画布持续更新、从重复格显示、双击恢复、虚拟屏丢失与重新检查、关闭前全部恢复、同模块重开、失效源及初始化期间关闭。request_cache 强制工作超过首个 250ms 回复预算，验证 IO_PENDING 重试及已完成结果重放只执行一次；同编号不同内容拒绝，新编号允许明确重试。

重连检查必须在再次隐藏前确认三个源仍在原位置且恢复记录清空，防止把重连引起的位置变化误当成新的原位置。请求测试另以可控初始化阻塞，验证显示操作不能提前清除检查点、零记录时也不能提前释放、返回可重试忙碌且初始化结束后可成功释放；仅用隔离管道、假显示操作及明确无效句柄。

### 用户验收与可选开发工具

用户已选择先接入正式 DLL，再统一验收大漠。实际验收采用 output DLL、原 14 参数易语言示例及画布右键操作。以下 --park 工具仅作可选开发入口，不要求用户运行，不放入 output。

驱动已安装后，在 PowerShell 中用当前真实 HWND 替换最后一个数值：

```powershell
& 'D:\Projects-tools\屏幕墙\out\build\x86\Release\recovery_integration_tests.exe' --park 'D:\Projects-tools\屏幕墙\out\build\x86\Release\GameWindowMapper.dll' 真实窗口句柄
```

工具只登记这个 HWND，移到本项目虚拟屏后等待回车；这时用户验证大漠后台绑定、输入和画面更新。完成后在工具控制台按回车，确认恢复原位置。工具退出时独立恢复程序仍负责保护。该工具不会创建映射画布、也不代表正式 UI；用户明确选择 HWND 并手动运行，不自动移动其游戏。此人工模式尚待用户实测。

打包只更新两份正式文件并比对哈希，保留用户既有 .e、图片及说明附件。实际结果分别记录后端短测、原生 UI、用户易语言/大漠，见 TEST_REPORT.md；锁屏／安全桌面导致的失败轮次不计通过，不通过修改系统安全设置消除该限制。

## REQ-GWM-001 基础短回归约定

本轮只运行短验证，不追加旧方案的100次启停、30分钟/16路压力矩阵。

1. 检查 x86 PE：只有一个 WM_StartMapping 固定导出，不含停止、设置、查询和测试专用导出。
2. 使用本轮新建的两个 GDI 窗口作为真实 WGC 源；乱序、重复 HWND 和空槽位启动。验证实际合成像素、可选底图及复制输入后画面不变。
3. 检查配置截断、容量不足和损坏图片被拒绝；运行中重复启动返回3。
4. 四次启动/关闭/重开短循环，依次传高级配置、原始BMP、原始PNG、用户JPEG，三次重开保持宿主DLL加载；不调用 Stop。最后一次调用方释放 LoadLibrary 引用后，活动画布仍正常，关闭后模块自动卸载，源窗口继续存在。无效HWND显示直传底图，正常HWND仍显示WGC画面。
5. 打包只生成/更新 output 的 DLL 和使用说明，DLL 与构建哈希一致；保留该目录的用户资产。demo.e 原样保存在 examples，不改动 input。

测试命令：scripts/build.ps1 -Test，执行 single_entry_lifecycle 和 gpu_geometry；实际 WGC 最大化几何测试源码保留，本轮不重跑无关检查。

易语言和其他目标窗口由用户验证，报告必须区分本轮原生短验证、旧版记事本/动态源历史结果与待用户测试。
