# 测试计划 — REQ-GWM-001

## 原型阶段

- 单文件无远程资源，嵌入LOGO与input原图字节一致；脚本语法、DOM引用和可访问标签检查。
- 浏览器验证布局切换、修改ROI/标题/HWND、各状态、底图上传、追加/清空/重置、双击模拟激活、纯画布及尺寸调整。
- 验证1440、1024、768、375宽度及长标题；不发生页面水平溢出；低宽度网格保持所选列数，不自动重排。
- HTML演示不得对真实HWND进行操作；不得将其帧率、画面变化解释成WGC性能。

## 记事本真实窗口（正式DLL阶段，开发端执行）

创建多个新的独立顶层记事本窗口，记录本轮所有权及HWND；不可用同一窗口多个标签页代替。写入编号、中文、多行文本，不保存测试文本。

1. 打乱句柄顺序，在2×2、3×4、4×4网格验证位置、重复HWND和空槽位。
2. 输入与滚动，观察更新；测试客户区0,0,800,600和偏移ROI，调整源窗口与画布尺寸。
3. 遮挡、移动、最小化、恢复；记录各状态，不假定最小化继续出画面。
4. 关闭其中一个窗口，确认该槽位占位且其余编号不动；绑定新HWND后恢复。
5. 双击每个格子，验证对应记事本激活；系统拒绝时状态如实显示。
6. 完成后仅关闭本轮创建窗口，不关闭用户既有记事本或保存测试文本。

## 自动化动态源及ABI

自带GDI/D3D11源绘制角标、网格、已知内容与帧号；分别构建x86/x64源。验证ROI像素、尺寸/DPI、实时性、设备丢失恢复，不以收到FrameArrived等同内容更新。

覆盖并发更新、整数组原子替换、旧回调代次失效、空数组、重复句柄、容量不足、参数溢出、损坏PNG/BMP、中文编码、缓冲区长度、重复Stop和重复Start。

执行100次启动/停止并随后卸载；检查线程、窗口句柄和GPU资源释放。只有Stop返回后测试FreeLibrary。

## 性能

1/4/12/16路动态源，分别15/30/60FPS，16路持续30分钟。采集各路收帧率、画布呈现率、CPU、GPU、内存和显存趋势；不积压帧，不崩溃或持续泄漏。16路60FPS为优化目标，达不到时记录实际值和瓶颈，不伪造通过。

## 用户验收

开发端自测完成后通知用户并交付DLL、易语言声明/样例、ICO、步骤和日志导出方式。用户在易语言验证加载、数组/字节集、并发调用及其他应用HWND；本机C++宿主验证不能替代真实易语言结果。
