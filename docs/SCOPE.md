# Scope

## 范围内

REQ-GWM-001：原生 x86 DLL、WGC 窗口捕获、客户区裁剪、D3D11 合成、可缩放固定槽位画布、标题、BMP/PNG 底图、双击激活、运行中接口更新、状态查询及图标资源。

HTML 是一次性审阅载体。参数面板、模拟窗口和反馈记录只用于原型演示，不进入正式画布 UI。

## 范围外

完全离屏隐藏、源窗口重新挂父窗口、注入/Hook、桌面截图降级、输入穿透、键盘映射、OCR/YOLO、像素数据导出、独立后台 EXE、x64 DLL、自动适配所有受保护窗口。

## 分工

开发端负责记事本、自带 GDI/D3D11 动态源、ABI调用及资源/性能测试；用户负责真实易语言和其他应用。未返回用户结果时明确标为待验证。
